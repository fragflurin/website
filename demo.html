FragFlurin selbst ausprobieren

Interaktive Beispiel-Demo – die vollständige App befindet sich noch in Entwicklung.

Wähle eine Situation. Du siehst, wie FragFlurin später in einfachen Schritten antworten soll. Alle Antworten sind feste Beispiele. Die Demo stellt keine KI-Anfragen und übermittelt keine eigenen Eingaben. Wie auf der ganzen Website läuft eine anonyme Reichweitenmessung (Cloudflare Web Analytics).

Mein Handy ist ein:

«Wie speichere ich eine Telefonnummer?»

So geht es:

Auf dem iPhone

  1. Suchen Sie auf Ihrem iPhone die App «Kontakte» und öffnen Sie sie. Das Symbol zeigt eine Person auf grauem Grund.
  2. Tippen Sie oben rechts auf das Pluszeichen (+).
  3. Tragen Sie den Namen und die Telefonnummer ein.
  4. Tippen Sie oben rechts auf «Fertig».

Auf einem Android-Handy

  1. Suchen Sie auf Ihrem Handy die App «Kontakte» und öffnen Sie sie.
  2. Tippen Sie auf das Pluszeichen (+) oder auf «Kontakt erstellen».
  3. Tragen Sie den Namen und die Telefonnummer ein.
  4. Tippen Sie auf «Speichern».

Die Namen und Symbole können je nach Handy etwas anders aussehen.

«Ich finde WhatsApp nach dem Update nicht mehr.»

So geht es:

Auf dem iPhone

  1. Gehen Sie auf den Startbildschirm Ihres iPhones. Das ist die Seite mit den vielen kleinen Symbolen.
  2. Legen Sie den Finger ungefähr in die Mitte des Bildschirms und wischen Sie nach unten.
  3. Tippen Sie oben in das Suchfeld und schreiben Sie «WhatsApp».
  4. Wenn das grüne WhatsApp-Symbol erscheint, tippen Sie darauf.

Auf einem Android-Handy

  1. Gehen Sie auf den Startbildschirm Ihres Handys. Das ist die Seite mit den vielen kleinen Symbolen.
  2. Legen Sie den Finger unten auf den Bildschirm und wischen Sie nach oben.
  3. Tippen Sie oben in das Suchfeld und schreiben Sie «WhatsApp».
  4. Wenn das grüne WhatsApp-Symbol erscheint, tippen Sie darauf.

Ein Update löscht die App nicht automatisch. Erscheint WhatsApp nicht, fragen Sie eine vertraute Person, bevor Sie etwas neu installieren. Bei manchen Handys ist die Bedienung etwas anders.

«Eine Nachricht sagt, mein Paket sei blockiert und ich müsse auf einen Link klicken.»

So gehen Sie vor:

  1. Tippen Sie nicht auf den Link in der Nachricht.
  2. Öffnen Sie stattdessen die offizielle App oder Website des Paketdienstes selbst.
  3. Prüfen Sie dort, ob wirklich ein Paket auf Sie wartet.
  4. Wenn Sie unsicher sind, fragen Sie eine vertraute Person.

Warnzeichen sind Zeitdruck und unerwartete Zahlungsaufforderungen. Dies ist nur ein Beispiel und keine echte Sicherheitsprüfung einer Nachricht.
