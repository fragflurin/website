FragFlurin selbst ausprobieren

Interaktive Beispiel-Demo – die vollständige App befindet sich noch in Entwicklung.

Wähle eine Situation. Du siehst, wie FragFlurin später in einfachen Schritten antworten soll. Alle Antworten sind feste Beispiele. Es wird nichts eingegeben, nichts gespeichert und keine KI befragt.

«Wie speichere ich eine Telefonnummer?»

So geht es:

  1. Öffnen Sie die Kontakte-App auf Ihrem Handy.
  2. Tippen Sie auf das Pluszeichen.
  3. Geben Sie den Namen und die Telefonnummer ein.
  4. Tippen Sie auf «Speichern» oder «Sichern».

Die genauen Schritte können je nach Handy unterschiedlich sein.

«Ich finde WhatsApp nach dem Update nicht mehr.»

So geht es:

  1. Öffnen Sie die App-Suche auf Ihrem Handy.
  2. Suchen Sie nach «WhatsApp».
  3. Wenn WhatsApp erscheint, tippen Sie auf das Symbol.
  4. Wenn die App nicht erscheint, fragen Sie eine vertraute Person, bevor Sie etwas neu installieren.

Ein Update bedeutet nicht automatisch, dass die App gelöscht wurde.

«Eine Nachricht sagt, mein Paket sei blockiert und ich müsse auf einen Link klicken.»

So gehen Sie vor:

  1. Öffnen Sie den Link vorerst nicht.
  2. Unerwartete Zahlungsaufforderungen und Zeitdruck sind Warnzeichen.
  3. Prüfen Sie die Sendung ausschliesslich über die offizielle Website oder App des Paketdienstes.
  4. Wenn Sie unsicher sind, fragen Sie eine vertraute Person.

Dies ist nur ein Beispiel und keine echte Sicherheitsprüfung einer Nachricht.
